Примечания:
- Все сценарии запускаются с прогревом (60–120 сек) и фиксированными таймаутами клиента, чтобы отличать таймауты на стороне сервиса от клиентских.
- Метрики снимаются как на уровне клиента (k6/Gatling), так и на уровне сервиса (APM/Prometheus) для корреляции и поиска узких мест.
- Для слоёв, зависящих от внешних квот, тест «Шум API до LLM» выполняется отдельно, чтобы результаты были детерминированными.

## Когда нагрузочное тестирование можно отложить

Если функция экспериментальная и не задействована в критичных сценариях, нагрузочное тестирование можно отложить до:
- появления стабильной схемы API и SLA требований;
- достижения дневного трафика ≥ 30% от ожиданий пика, либо появления признаков деградации (ошибки ≥ 0.5%, рост p95 > 20% неделю к неделе);
- фиксации критического пути (трассировки в APM) без неопределённостей.
